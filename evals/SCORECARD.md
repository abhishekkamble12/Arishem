## Caveats

- **This run is incomplete:** 11 of 72 questions are not answered yet (unan-09, unan-10, unan-11, unan-12, unan-13, unan-14, unan-15, unan-16, ood-01, ood-02, ood-03), all of them unanswerable; the generator hit Groq's daily token cap. Every answerable question is complete.
- The corpus and questions are synthetic fixtures written for this eval. They test behaviour — distractors, multi-hop, abstention, injection — not performance on any real company's documents.
- Answer correctness checks that required facts appear, by whole-token match. It cannot tell a fact stated correctly from one mentioned and then contradicted.
- Judged faithfulness is only as good as the judge; `evals/judge_control.py` checks it scores fabricated answers near 0 before its scores are trusted.
- 61 questions is still small; differences of a few points between runs are noise.
- Latency here is dominated by Groq's per-minute rate limit, because the questions run back to back with the fallback model disabled. It is not production latency.
